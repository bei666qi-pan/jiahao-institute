# 嘉豪角色喜剧实验：未通过体验验收

2026-09-05，基于e593eb6。用户要求达到认可为好玩的程度再交付。本记录只是实验检查点，不是通过版。

## 设计改变

原模式“玩家出糗，角色提醒”让嘉豪沦为普通同学。现在四个场景由嘉豪自己把话说满，并公开一个可拆穿的破绽：

- 课堂：自称全会，物理书和近代史黑板不匹配。
- 小组作业：声称脑内完稿，正文为空。
- 自拍：坚持原片直出，门框却弯了。
- KTV：自称闭眼能唱，歌词未出就抢唱。

角色的嘴硬应与自己实际动作形成反差，玩家可以捧杀、拆穿或合作。新增证据条也进入分享预览和实际卡片，避免离开页面读不懂。没有加入评分、领奖或额外调用的导演。其他日常场景保留，原视觉结构不变。

## 真实结果，不以技术通过替代好玩

本轮character标签17次真实模型请求，17次上游成功，usage17,294 tokens。两个初试、两个新留出、一个真实浏览器完整局，共五局完成；自拍两次后第三次被原定90次全局调用上限阻止。预算拦截没有请求供应商，页面503并停在第二轮，不能称为模型格式失败。全局账本实际已90次，未自行扩大预算，未重试掩盖。

有效证据：

- 玩家把物理书拿去垫桌脚，嘉豪找补“垫桌脚也算个微观应用场景”，手上开始借历史书。这有输入对应和被拆穿后的实际退让。
- 小组作业口头朗读高深开头，却退回“先填个标题副标”，光标还在空行，嘴与动作的反差比单独吐槽有效。
- KTV普通玩家只说“你继续，我不唱”“我不会数，你自己来”，嘉豪说“刚才那是给你个参与感”，自己却再次进错拍。没有逼玩家唱，但拖了两轮才行动。

未通过的证据：

- 初试课堂大段伪理论，笑点主要靠玩家提出“辛亥革命的加速度”。第二轮缩短后，普通玩家仍遇到“嘉豪向玩家借笔→玩家问你不是有笔吗→嘉豪说不能借给你”的借用方向错误，以及重复找目录。
- 真实浏览器小组作业最终要求嘉豪就夜宵涨价写一句。他提出一句后又追问“那第二句呢？要不你接一下”，收场没有干净结束。
- 自拍复拍只有举起手机，没有明确拍完。第三次受预算中止，不宣称完整体验。
- 独立玩家对课堂明确不太想再玩，对KTV只有一点再试另一种回应的动机。这只是模拟反馈，不是留存数据。

独立评审只读可见轨迹，没有看新提示；认可角色辨识比前版明确，未认可整版通过。开发者判断同样是：有局部笑点，但尚不足以作为愿意推荐的完整体验交付。
