## 产品快照与本轮改变

这是短篇角色喜剧：嘉豪先把话说满，玩家拆台、捧场或合作，观察他是否真的动手以及如何继续嘴硬。首页推荐自拍：他说没开滤镜，门框却弯了。校园、工作、朋友共 15 个场景保留，七日联赛与鉴定等旧入口继续存在；不新增积分、付费服务或真实通知。

台词不再充当动作账本。代码检查动作合法性并投影公开事实；书本、文档、自拍相框和演唱文字把变化展示出来。自拍采用已有嘉豪素材与 SVG 门框示意，不是实际修图服务。照片删除、关闭滤镜、文档新增、通知改写和离开均有适用场景内的状态检查；缺少道具视图的旧场景使用事实列表。

分享默认选择首个实际动作回合，无动作则最后回合，可自行换选。公开前预览“选中的一招和收场”；非末招补最后一次玩家输入，使收场有上下文。确认高光持久化，刷新不换内容；二维码未公开时只指向同题，确认后指向挑战；原链接可由所有者撤销。

## 可定位的前后证据与尚存问题

- 早期 `r4-photo-help`：玩家要求举高手机示范，嘉豪回答“我示范一下”，但三轮 `event` 都为空，事实仍只有滤镜开启。说了要做不算已做。本轮把示范及照片状态纳入代码投影，不能由台词自行宣告。
- `player-group`：要求写一段后生成“数字化转型”等通用套话；再要求具体例子返回业务 502，保留原进度。不能把上游 HTTP 200 算成成功互动。
- `notice-final-canteen`：玩家“那份你拿吧，我这两个菜够吃了”，实际变化为奶龙拿最后一份里脊；事实保留玩家原有两个肉菜，不再串归属。下一句“我先找座了”后角色离开，玩法结束。
- `notice-final-overtime`：玩家要求把“提前”改为“准时”，代码记录通知为“活动将于明天下午三点准时开始。”；玩家下班后嘉豪收回通知，不继续拦电梯。嘴硬仍有“语义降噪”“版本感”等术语，自然程度属于主观局限。
- `notice-final-photo`：玩家建议头像构图，角色仍反复解释门框，有角色特色但容易重复；玩家明确不参谋后收手机，保留照片和滤镜状态，不虚构已经删除。
- **保留失败样本 `notice-final-group`**：修改第三道采访问题被追加为第二条同编号问题；随后“删掉旧的那条，留完整的”返回业务 502，状态留在第二轮。该原始样本仍是不通过；后续修订能力复验见下文，不能覆盖删除原失败。

### 文档修订的两次根因与最后复验

第一次根因是动作集合只有追加正文，修改要求也走 `write`，旧条目被重复追加。新增 `revise_document` 后，代码以修改后的完整正文替换，保留未要求修改的内容；相应回归检查修改和删除，不再把追加当修订。

第二次根因是“请写/改文档”仍允许 `hold`，角色只承诺而不执行。`document-final-group` 第一请求 JSON 不合法，业务 502；玩家显式 retry 后三次请求完成，但首轮仅承诺、没有正文，因此不能称为完整修好。随后把明确编辑要求的合法动作收窄为有正文时修订、无正文时写入；只是聊天、拒绝编辑或退出不强迫写作。此限制不保证模型一次满足数量或内容质量。

最新 `edit-final-group` 三轮均完成：首轮要三个采访问题却只给一个；第二轮有空白第二题；第三轮根据明确补充输入，最终正文保留完整三题，修改未再次重复追加。**修订能力通过该样本，首次按数量完成仍未满足**，不能包装成一次成功。

`edit-final-photo` 三轮中，提出示范后确实举高手机、收下巴，退出时收手机；`edit-final-class` 确实换书、写出年份题并结束，但把题目与答案一起写出，复习挑战性弱。三局共 9 次真实模型请求、无业务失败，开放式趣味仍有分歧。

`closing-final-browser-browser.json` 标记 passed:true、shareRevoked:true，六条事件对应两个身份各三轮，完整分享、卡片下载及撤销已走真实浏览器；实际图片已由主代理检查。早先 `local-final-browser.json` 的第二轮等待失败与账本一次上游传输超时保留，不能以本次通过掩盖。独立最终评审尚待汇总，尚未上线。

上述例子是模拟玩家与真实模型业务链路，不是用户留存研究。图像只是公开状态示意；不能以局部趣味、模型自述或技术通过证明所有人愿意继续玩和传播。

## 五分钟真人路线与复用

1. 打开本地首页，点“先接一招”，看自拍与弯门框。
2. 让嘉豪关闭滤镜，核对门框由弯变直；再夸或拆一句，观察嘴硬是否回应具体输入。
3. 完成后看默认动作回合，手动切换高光；打开预览，核对末轮输入和收场，再决定是否公开。
4. 用另一浏览器身份打开挑战链接，完成同题，查看双方不同结果；回所有者链接撤销。
5. 换校园作业或工作通知，观察正文变化；刷新确认道具状态仍在。若复现上述修订问题，保留失败，不以重试掩盖。

启动和回归命令见 [TESTING.md](../TESTING.md)。真实玩家适配器 `scripts/scene-playtest.mjs` 使用 `PLAYTEST_URL=http://127.0.0.1:5194`；每步读真实反馈后再决定行动，会话文件与可见轨迹留仓库外。没有通过产品接口之外单独调用模型来冒充用户完成动作。
